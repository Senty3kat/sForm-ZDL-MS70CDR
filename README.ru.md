# sForm — LFO с гибкой формой волны и гитарный синт на одном генераторе для Zoom MS-70CDR

[English version](README.md)

![sForm на экране MS-70CDR](docs/screen.png)

**Релиз 1.00.** Свой эффект `.ZDL` для **Zoom MS-70CDR** (прошивка 2.10).
Один генератор с настраиваемой формой волны, у которого три работы:

- **источник модуляции для [XDuck](https://github.com/Senty3kat/XDuck-ZDL-MS70CDR)** —
  в цепочке sForm → XDuck инструмент гейтится, приседает, дрожит или гуляет по панораме
  точно по волне sForm, от 0.001 Гц до звуковых частот;
- **дрон** на любой ноте от C0 до A7;
- **одноголосный гитарный синт** — генератор идёт за высотой сыгранной ноты (трекинг по IN L)
  со сдвигом до четырёх октав вниз и двух вверх.

> Сделан для **MS-70CDR**: выход пишется в канал R, а XDuck нужны два раздельных входа CDR.

## Установка

1. Скачай [`release/sForm.ZDL`](release/sForm.ZDL) и [`release/sForm.png`](release/sForm.png)
   (PNG — картинка для Effect Manager, клади рядом с ZDL).
2. Закрой Ableton и вкладки браузера с Web MIDI — они занимают порт педали.
3. Установи через Zoom Effect Manager. Эффект в категории **Dynamics**, номер **502**.
   Effect Manager не заменяет эффект с тем же номером: старый sForm сначала удали
   (тестовые сборки 0.11 и старше были с номером 488 в Delay — их тоже удали вручную).

## Экран

Одно окошко внизу слева со значением первой ручки текущей страницы; на 1-й странице это
**Wave**, нарисованная своей формой: синус, треугольник, пила вверх, пила вниз, квадрат,
S&H, дрейф.

## Ручки (3 страницы)

| Стр. | Ручка | Что делает |
|---|---|---|
| 1 | **Wave** | `Sine`, `Tri`, `SawUp`, `SawDn`, `Squar` (ширина — ручкой Skew), `S&H` (случайные ступеньки), `Drift` (плавный случайный). |
| 1 | **Rate** | 0.1…10.0 Гц с шагом 0.1 (на экране в Гц). Работает при Note = `Off`. |
| 1 | **Mult** | Множитель x.01 x.02 x.05 x0.1 x0.2 x0.5 x1 x2 x5 x10 x20 x50 x100 — Rate × Mult = 0.001 Гц…1 кГц. |
| 2 | **Skew** | Симметрия: где вершина у Sine/Tri/Saw; у Square — ширина импульса (50 = квадрат). |
| 2 | **Curve** | Изгиб формы: меньше 50 — круглее, 50 — как есть, больше 50 — резче. |
| 2 | **Smth** | Сглаживание 0…200 мс: скругляет углы Square / S&H; на ноте синта работает как фильтр. |
| 3 | **Out** | `XDuck` — волна уходит в XDuck по каналу R (служебный сигнал, слушать не нужно), L без изменений. `Drone` — генератор звучит в правом выходе, L без изменений. `DrnSt` — генератор в обоих выходах. |
| 3 | **Depth** | Out = XDuck: глубина волны. Drone / DrnSt: микс — 0 = только гитара, 50 = гитара и синт оба полностью, 100 = только синт. |
| 3 | **Note** | `Off` — скорость от Rate × Mult. `C0`…`A7` — генератор на этой ноте. `in-48`, `in-36`, `in-24`, `in-12`, `in`, `in+12`, `in+24` — высота гитары с IN L со сдвигом на октавы. |

### Трекинг (Note = `in…`)

- Одиночные ноты, не аккорды. Синт звучит, пока звучит гитара, и замолкает вместе с ней
  (открывается за ~2 мс, закрывается через ~75 мс тишины); между нотами держит последнюю высоту.
- Вверх высота идёт свободно (хаммеры, бенды), вниз — только по новой громкой ноте:
  если отпустить лад (струна звенит открытой), синт не «улетает» вниз; глушение правой
  рукой просто останавливает ноту.
- С Out = `XDuck` волна идёт на высоте сыгранной ноты: через XDuck гитара модулируется
  своей же нотой (`in-48`/`in-36` дают ритмичную пульсацию, привязанную к высоте).

## Работа с XDuck

Цепочка **sForm → XDuck** (sForm сразу перед XDuck), у sForm **Out = `XDuck`**, у XDuck
**Route = `sForm`** (или **`sFPan`** для автопанорамы). XDuck читает волну на каждом
сэмпле — без детектора и огибающей — и точно повторяет форму на любой частоте:

| XDuck Type | Громкость инструмента |
|---|---|
| `Duck` | 1 − волна |
| `Tex` | повторяет волну |
| `Gate` | открывается, где волна пересекает Thrsh (30 = середина), Ratio — крутизна |

Глубина — ручка Range у XDuck. По каналу R sForm передаёт на каждую пару сэмплов два
значения — волну и волну со сдвигом на полпериода; благодаря этому работает `sFPan`.

## Сборка из исходников

Тулчейн [themanro/ZoomMultistompZDL](https://github.com/themanro/ZoomMultistompZDL)
и компилятор TI C6000 8.5.0.LTS.

1. Склонируй форк themanro и скопируй `src/sform/` в `src/custom/sform/`.
2. Скопируй файлы из `toolchain-patches/` поверх тех же путей в форке (целые файлы, основа —
   форк на 2026-10-18; тот же набор, что в репозитории XDuck).
3. В `src/custom/sform/build.py` укажи `TI_ROOT` и `out_dir` и запусти
   `python src/custom/sform/build.py`.

`sform.c` — по правилам безопасного DSP форка: без switch, математической библиотеки,
деления и static-массивов, состояние в арене `ctx[3]`. Фаза — 32-битный аккумулятор
(точно до 0.001 Гц). Трекер — подстраиваемый фильтр ~1.3 × текущей высоты, триггер Шмитта
и счёт периода с защитой от ошибок на октаву. Подписи Rate и Note считаются прямо в C —
таблицами они занимали ~9 КБ.
