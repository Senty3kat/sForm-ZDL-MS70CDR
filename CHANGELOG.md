# sForm — история версий / version history

(на русском, как вёл автор / in Russian, the author's own log)

```text
sForm — история версий
LFO, который пишет волну в правый канал. Сделан как источник ключа для XDuck.
Номер эффекта 502 (до 0.12 был 488). Перед установкой новой версии удаляй старый sForm в Effect Manager.

Как использовать с XDuck:
  цепочка: sForm -> XDuck (sForm первым, XDuck сразу после)
  с 0.12: sForm Out = Link, XDuck Route = sForm (XDuck 1.16+) — точное следование волне.
  по-старому: Out = Repl, XDuck Route = KeyR, Freq = Full (или Out = Tone и Freq = 880)
  Duck = качание по форме LFO, Gate = рубленый ритм, Tex = плавное тремоло.

0.10  (ТЕСТ, файл sForm.ZDL)
      - Первая сборка: звук готов, картинка экрана временная (простая, с названием).
      - Ручки (9):
        стр.1  Rate (0.05-20 Гц, 50 = 1 Гц), Mult (/8 /4 /3 /2 x1 x2 x3 x4 x8),
               Wave (Sine Tri SawUp SawDn Squar Pulse S&H Drift)
        стр.2  Skew (симметрия / ширина импульса), Curve (изгиб: <50 мягче, >50 резче),
               Smth (сглаживание 0-200 мс)
        стр.3  Depth (размах), Phase (сдвиг фазы), Out (Repl Mix Mod Tone)
      - Левый канал проходит без изменений.

0.11  (ТЕСТ, файлы sForm.ZDL + sForm.png)
      - Новая картинка экрана: гусеница SILKFORM по твоему референсу (порог 0.44).
      - Как в XDuck 1.15: одно окошко значения слева внизу (вращающаяся стрелка
        вместо квадратной крутилки), превью для Effect Manager с номером версии.
      - Ручки переставлены, чтобы в окошке (1-я ручка страницы) было самое важное:
        стр.1  Wave, Rate, Mult
        стр.2  Skew, Curve, Smth
        стр.3  Out, Depth, Phase
      - Звук не менялся.

0.12  (ТЕСТ, ставить вместе с XDuck 1.16)
      - НОВЫЙ НОМЕР ЭФФЕКТА 502 (был 488 — совпадал с эффектом matujuice).
        Категория теперь Dynamics (была Delay). Старый номер 488 Effect Manager
        считает другим эффектом: удали старую версию вручную; в сохранённых
        патчах эффект придётся поставить заново.
      - Связка с XDuck: новый Out = Link (стоит по умолчанию). sForm пишет в R
        значение LFO в особом виде, XDuck с Route = sForm читает его напрямую,
        каждый сэмпл, без детектора и без атаки/холда/релиза. Работает на любой
        частоте, от 0.01 Гц до 20 кГц. Link — служебный сигнал, слушать его не нужно.
        Старые режимы остались: Repl, Mix, Mod, Tone.
      - Частота: Rate 1..1000 Гц (на экране в Гц, шкала логарифмическая),
        Mult x.01 x.02 x.05 x0.1 x0.2 x0.5 x1 x2 x5 x10 x20 x50 x100.
        Итог 0.01 Гц .. 20 кГц (выше 20 кГц не поднимается).
        По умолчанию 1 Гц x1.
      - Генератор фазы стал точным на сверхмедленных частотах.
      - Надпись SILKFORM на экране перерисована: контуры без разрывов, без шума.
      - Порядок ручек прежний (Wave Rate Mult / Skew Curve Smth / Out Depth Phase).

0.13  (ТЕСТ, ставить вместе с XDuck 1.17)
      - Rate: 0.1 .. 10.0 Гц ровно с шагом 0.1 (по умолчанию 1.0). Mult прежний,
        итог 0.001 Гц .. 1 кГц.
      - Новая ручка Note вместо Phase (стр.3, третья): Off или нота C1..B7
        (A4 = 440 Гц). Если нота выбрана, LFO идёт ровно на её частоте,
        Rate и Mult не действуют — через XDuck звук «звучит» этой нотой.
      - Pulse убран: Square теперь с шириной от Skew (50 = квадрат, меньше/больше = импульс).
        Волны: Sine Tri SawUp SawDn Squar S&H Drift.
      - Link передаёт сразу две волны: основную и сдвинутую на 180° (для
        панорамы в XDuck, Route = sFPan). У S&H и Drift вторая — зеркальная.
      - Ручки: стр.1 Wave Rate Mult, стр.2 Skew Curve Smth, стр.3 Out Depth Note.

0.14  (ТЕСТ, ставить вместе с XDuck 1.18)
      - Out теперь только три режима:
          XDuck — бывший Link: служебный сигнал для XDuck (Route sForm / sFPan), L не трогается.
          Drone — генератор звучит в правом выходе, L проходит как есть.
          DrnSt — генератор звучит в обоих выходах, вместе с гитарой с входа L.
        Repl, Mix, Mod, Tone убраны. Громкость дрона — Depth.
      - sForm теперь ещё и простой одноголосный синтезатор на одном генераторе:
        Wave/Skew/Curve — форма, Smth — смягчение (как фильтр), Note — высота.
      - Note: добавлена октава 0 (C0..B7), а после B7 — in-24, in-12, in, in+12, in+24:
        высота берётся с гитары на входе L (трекинг), со сдвигом на ±1–2 октавы.
        В этих режимах дрон ещё и повторяет громкость гитары (гитарный синт),
        а в режиме XDuck волна идёт на частоте сыгранной ноты.
        Трекинг простой: лучше всего ловит одиночные ноты, без аккордов.

0.15  (ТЕСТ)
      - Окошко внизу слева сдвинуто вправо (x=14, как у заводских эффектов) —
        раньше его закрывала плашка «слева есть ещё эффект».
      - Вместо стрелки в окошке рисуется форма волны: синус, треугольник,
        пила вверх, пила вниз, квадрат, S&H (ступеньки), Drift (плавный случайный).
        Окошко показывает первую ручку текущей страницы: на стр.1 это Wave.
        На стр.2 (Skew) и стр.3 (Out) картинка тоже меняется, но там она
        не соответствует волне — так устроена педаль, одно окошко на все страницы.
      - Звук не менялся.

0.16  (ТЕСТ)
      - Исправлен in+24: у ручки Note больше 100 положений, и значение 101 педаль
        присылала так, что оно читалось как нота C0 (16 Гц) — отсюда «дичь».
      - Добавлены in-48 и in-36. Теперь после B7: in-48 in-36 in-24 in-12 in in+12 in+24.
      - Drone и DrnSt: синт держит ровную громкость (не затухает вместе с гитарой),
        гитара на входе L задаёт только высоту; между нотами держится последняя.
        Depth в этих режимах — баланс: 0 = только гитара, 100 = только синт.
        Синт в 2 раза громче. В DrnSt на оба выхода идёт этот баланс.
        В Drone левый выход по-прежнему без изменений.
      - Значки пилы рисуются одним зубцом (две линии).

0.17  (ТЕСТ — записалась, работает)
      - 0.16 не записывалась (FS.bin size mismatch): у ручки Note было 104 положения.
        Вернул 102, как в 0.14/0.15. Для этого убраны две верхние ноты A#7 и B7.
        Note: Off, C0..A7, in-48 in-36 in-24 in-12 in in+12 in+24.

0.18  (ТЕСТ)
      - Режимы in в Drone/DrnSt: синт звучит только пока звучит гитара
        (открывается за ~2 мс, закрывается за ~75 мс после тишины).
        С фиксированной нотой или частотой дрон звучит всегда, как раньше.
      - Depth в Drone/DrnSt — настоящий микс:
          0   = только гитара
          50  = гитара и синт, оба на полной громкости
          100 = только синт

1.00  (релиз на GitHub)
      - Трекинг: высота больше не «улетает вниз», когда отпускаешь лад.
        Вверх высота идёт свободно (хаммеры, бенды), вниз — только по новой
        громкой ноте; на затухании допускается лишь лёгкое вибрато (~3%).
        Глушение правой рукой, как и раньше, просто останавливает ноту.
        Атака новой ноты ловится чувствительнее.
      - Синт в Drone/DrnSt на 3 дБ тише. Depth 50 по-прежнему = гитара + синт полностью.
      - Значки треугольника и пил меньше.
```
